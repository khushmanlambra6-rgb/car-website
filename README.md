# Velora Drive — Premium Car Rental & Automobile Website

A 15-page static car rental and automobile experience built with HTML5, CSS3, and Vanilla JavaScript only.

## Run
Open `index.html` in a modern browser. No build step or server is required.

## Included
- 15 connected pages
- Responsive navigation and mobile menu
- Vehicle filtering and sorting
- Vehicle details gallery
- localStorage comparison list
- Rental booking calculator and validation
- FAQ accordion
- Contact/newsletter validation
- Toast notifications
- Responsive tables and forms

## Photography
The project uses remote automobile photography URLs from Unsplash and other publicly accessible image sources for the demo. Images are displayed with `object-fit: cover` and are not stretched.

## Demo disclaimer
This is a front-end demonstration. Booking confirmation, comparison, and forms do not connect to a real payment or reservation backend.
